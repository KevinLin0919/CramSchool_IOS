# 浮島

給補習班老師用的考卷批改 App（iPhone、iPad，iOS 17 以上）。

老師把手機對著學生的考卷，App 會即時在畫面上標出每一題的對錯，
不用再一題一題對答案。

## 怎麼用

1. **考卷**：選要批改的考卷模板（由模板管理者事先建好）。
2. **掃描**：鏡頭對著考卷移動，掃到哪裡就批到哪裡。雙面考卷批完一面會自動換到下一面。
3. **結果**：看整份考卷的批改結果，必要時修正，結果會自動傳回伺服器。

批完一頁後，畫面只留下要訂正的格子，老師可以照著用紅筆改。

## 三種判定

| 顏色 | 意思 |
|---|---|
| 綠 | 對 |
| 紅 | 錯，旁邊會寫正確答案 |
| 橘 | App 沒把握，請老師自己看 |

App 讀不出來的字**不會**算學生錯，而是交給老師判斷。
結果頁只顯示三種判定各有幾題，不算分數。

## 不需要網路也能批改

批改全部在手機上完成。只要先同步過一次模板，沒有網路也能批完整疊考卷，
連上網後再把結果傳回伺服器（[浮島 後端](https://github.com/KevinLin0919/CramSchool_Backend)）。

透過 TestFlight 安裝，請向補習班的管理員索取邀請。
